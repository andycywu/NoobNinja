2. **ModelSummarizer** (`summarizer.js`) - 模型摘要分析器

## 📝 使用指南

### 快速開始
1. 啟動 Netron：`npx serve -p 8080 source`
2. 載入模型檔案
3. 點擊 "Explain" 按鈕
4. 選擇解釋模式
5. 查看結果並匯出

### 進階配置
- **設定 Ollama**：本地 LLM 服務
- **配置 OpenAI**：雲端 API 整合
- **自定義規則**：擴展解釋邏輯
- **客製化匯出**：調整 Model Card 格式
