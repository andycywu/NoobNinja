## 🚀 使用方法

1. **啟動應用**
   ```bash
   npm start
   ```

2. **載入模型**
   - 拖放模型文件到界面
   - 或使用檔案選擇器

3. **查看解釋**
   - 點擊工具欄的 "模型小白解碼器" 按鈕
   - 查看帶有信心度和溯源徽章的解釋

4. **配置設定**
   - 點擊工具欄的設定按鈕 ⚙️
   - 配置主題和 LLM 選項
   - 設定會自動保存

## 🎨 主題系統

支援明亮和黑暗兩種主題模式：

- **明亮模式**: 適合白天使用
- **黑暗模式**: 適合夜間使用，減少眼睛疲勞

主題切換會即時生效，無需重啟應用。

## 🔧 LLM 整合

支援多種 LLM 提供者：

- **OpenAI**: GPT-4, GPT-3.5-turbo
- **Anthropic**: Claude-3.5-sonnet, Claude-3-haiku
- **Google**: Gemini-1.5-pro
- **本地模型**: 支援自定義 API 端點

## 📊 信心度指標

- 🟢 **高信心度 (>80%)**: 綠色徽章，高可靠性
- 🟠 **中信心度 (50-80%)**: 橙色徽章，中等可靠性  
- 🔴 **低信心度 (<50%)**: 紅色徽章，建議謹慎參考

## 🔍 溯源透明度

每個解釋字段都標示數據來源：

- **LLM 分析**: AI 模型推理結果
- **啟發式規則**: 基於經驗的規則判斷
- **模型元數據**: 直接從模型文件讀取
